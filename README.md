# AI Systematic Review + Wiki

> **Under construction.** This template is still being built, so please don't use it for a real review yet.

A template for running an AI-assisted systematic literature review on your own research question. You:

1. bring search exports from PubMed, Web of Science, EBSCO, or any database that exports RIS
2. answer a short setup interview

An AI coding agent (Claude Code, Codex, or similar) then helps you work through these steps:

- **Screen and tier** every paper against your inclusion criteria, logging the reason for each decision
- **Validate** the AI's decisions on a random sample you re-screen blind, and report agreement (Cohen's kappa)
- **Report** results in an Excel workbook, with an optional PRISMA flowchart
- **Collect** full-text PDFs (LibKey, Unpaywall, or manual)
- **Build an Obsidian wiki** with paper summaries, extraction tables, concept pages, debates, quality appraisal, and a knowledge graph
- **Publish** the wiki as a searchable MkDocs website (local, GitHub Pages, or openEQUELLA)

The method was first used for a published sports-science systematic review at BYU-Idaho.

See the [design spec](docs/superpowers/specs/2026-11-03-ai-systematic-review-plus-wiki-design.md) for details.
